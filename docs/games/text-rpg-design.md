# 심연 강하 (가제) — 로그라이크 텍스트 RPG 기획서

> **상태:** 살아있는 캐논 문서(슬라이스마다 갱신). 슬라이스별 구현 계획은 `docs/plans/`를 따른다.
> **가제:** _심연 강하 / The Descent_ (변경 가능). 세계관·고유명은 모두 오리지널(IP 제약 0).
> **배경:** 사이트의 첫 게임(SRPG, `docs/games/archive/srpg-design.md`)에서 **로그라이크 텍스트 RPG로 피벗**. 텍스트 장르는 **순수 로직 비중이 크고 절차생성으로 콘텐츠가 자동 확보**돼 취미 규모에 더 맞는다.

---

## 1. 개요·비전

회원이 사이트(`/play`)에서 플레이하는 **로그라이크 던전 크롤러 — 텍스트 기반**. 끝없는 심연을 한 층씩 내려가며 무작위 조우(전투·보물·상점·휴식·함정·보스)를 헤쳐 **최대한 깊이** 도달한다. 죽으면 처음부터. **회원 리더보드**(최고 깊이/점수)로 경쟁.

- **플랫폼**: `/play` 라우트, **회원 전용**(`getMemberSession()` 없으면 `MemberGate`).
- **기술**: Next.js 16 + **순수 텍스트 UI**(three 없음). 게임 규칙은 순수 함수, 화면은 로그·버튼·HUD. 진행/점수는 Prisma(추후 슬라이스).
- **한 줄 피치**: "한 손에 들어오는 작은 던전. 시드 하나로 시작해 얼마나 깊이 내려가나."

### 디자인 필러

1. **순수 로직 + 절차생성** — 전투·이벤트·아이템·진행을 **시드 RNG 기반 순수 함수**로 → 단위 테스트 100%, 적은 코드로 많은 플레이(콘텐츠 자동 확보).
2. **결정론적 재현(시드 공유)** — 같은 시드 → 같은 런. 디버깅·테스트·"같은 던전 도전"이 가능.
3. **가벼움** — 무거운 3D 의존 제거(three 삭제). 일반 React + 서버 액션. 512MB 서버·번들 부담 0.
4. **접근성은 텍스트로 자연스럽게** — 시맨틱 버튼·`aria-live` 로그·키보드 전조작이 기본. 단 상태·결과를 항상 텍스트로 명확히.

## 3. 세계관·테마 (오리지널, 가벼운 플레이버)

대지가 갈라진 뒤 생긴 **심연(Abyss)** 으로 사람들은 유물과 답을 찾아 내려간다. 깊을수록 더 굶주린 것들이 기다린다. 깊은 서사는 두지 않고 **층 설명·조우 텍스트**로 분위기만 낸다(플레이버 표는 살아있는 문서).

- 톤: 음울한 다크 판타지, 짧고 건조한 문장. 예: _"3층. 물 떨어지는 소리. 어둠 속에서 무언가가 당신을 봤다."_

## 4. 코어 루프

```
런 시작(시드 선택/랜덤) → 1층
 └─▶ [층 진행] 여러 '걸음(step)'을 지나며 각 걸음에서 무작위 조우:
        전투 / 보물 / 상점 / 휴식 / 함정 / (N층마다)보스
        → 조우 해결(전투면 턴제) → 다음 걸음
     마지막 걸음(또는 보스 처치) → 더 깊이 내려가기 → 다음 층(적 강화)
 ▼
 사망(HP 0) 또는 자발적 귀환 → 점수 산정 → 리더보드(추후) → 처음부터
```

- **걸음(step)**: 층마다 K걸음(예 5~7), 각 걸음은 가중 테이블로 이벤트 1개. 보스는 층 끝.
- **하강**: 층 클리어 시 "내려가기" → 깊이 +1, 적·보상 스케일 상승.
- **종료**: HP 0 = 영구사망. 자발적 귀환(선택) 시 현재 점수 확정. 엔드리스(깊이 경쟁) + 마일스톤 보스.

## 5. 플레이어·스탯·성장

| 스탯       | 의미                             |
| ---------- | -------------------------------- |
| HP / maxHP | 생명. 0이면 사망                 |
| ATK        | 공격력(+무기)                    |
| DEF        | 방어력(+방어구)                  |
| GOLD       | 상점 재화                        |
| LV / XP    | 처치로 누적, 레벨업 시 스탯 상승 |
| LUCK(추후) | 치명·보상 확률 보정              |

- **장비**: 무기(ATK), 방어구(DEF) 각 1슬롯 + 소비 아이템 인벤토리(물약 등).
- **성장**: 전투 처치 → XP·골드. 레벨업(스탯↑) 또는 상점/보물로 장비·소비템 확보. 휴식에서 회복.

---

## 6. 적·전투 (턴제 텍스트)

- **적**: 종류별 스탯 테이블 + **깊이 스케일**(층↑ → HP/ATK↑). N층마다 보스(고HP·특수 행동).
- **턴**: 플레이어 행동 → 적 행동 반복. 플레이어 행동:
  - **공격**: dmg = max(1, ATK+무기 − (적 DEF)) ± 소량 변동(시드 RNG), 치명 확률.
  - **스킬**(직업/추후): 강타·방어·회복 등(쿨다운/자원).
  - **아이템**: 물약 등 즉시 사용.
  - **도망**: 확률 성공(실패 시 적 1회 공격). 보스는 도망 불가.
- **적 AI**: 단순(공격 위주, 일부 특수). **결정론**(시드) → 테스트 재현.
- 모든 수식은 순수 함수로 분리(밸런스는 살아있는 표, 플레이테스트 조정).

---

## 7. 이벤트·절차생성

- **이벤트 테이블**(걸음 단위, 깊이 가중): `전투`(주력) / `보물`(골드·아이템) / `상점`(구매·회복) / `휴식`(회복·강화) / `함정`(피해·디버프) / `보스`(층 끝).
- **절차생성**: 시드 PRNG로 층 구성(걸음 수·이벤트·적·보상)을 결정. **같은 시드 = 같은 던전**.
- 일부 이벤트는 **선택지**(예: "보물상자를 연다 / 지나친다", "수상한 약을 마신다") → 가벼운 분기·리스크.

---

## 8. 아이템·경제

- **무기/방어구**: 등급별 ATK/DEF. 상점 구매·보물 획득. 더 좋은 것 장착(교체).
- **소비템**: 체력 물약, 해독, 임시 버프 등.
- **골드**: 처치·보물로 획득, 상점에서 소비. 깊이별 가격·상품 스케일.

---

## 9. 진행·죽음·점수

- **점수**: `depth*가중 + gold + kills*가중 + 보스 보너스` (순수 함수, 살아있는 공식).
- **영구사망**: HP 0 → 런 종료, 점수 확정. 처음부터(새 시드 또는 같은 시드 재도전).
- **리더보드(추후)**: 회원별 **최고 깊이/점수**. 클리어 마일스톤(예: 보스 N 처치) 플래그.

---

## 10. 조작 · UX · 접근성

텍스트 장르라 **AGENTS.md 접근성 의무를 자연스럽게 충족**. 상태는 텍스트로 노출.

- **로그**: 시간순 이벤트/전투 로그. 새 줄은 `aria-live="polite"`(중요 사건·사망·레벨업은 `role="alert"`).
- **액션**: 상황별 시맨틱 `<button>`(전투=공격/스킬/아이템/도망, 이벤트=선택지, 층간=내려가기/귀환). **키보드 전조작**(Tab·Enter, 숫자 단축키 선택). 비활성은 `disabled`.
- **HUD**: HP/maxHP, 깊이(층), 골드, 장비, 레벨. 명확한 라벨·대비.
- **모션**: 타자기 효과 등은 `prefers-reduced-motion` 시 즉시 표시. 게임 로직 무관.
- **확인**: 되돌릴 수 없는 선택(귀환·위험 선택)은 확인 단계.

## 11. 기술 아키텍처

### 로직 / 렌더 분리(핵심)

```
lib/game/rogue/            ← 순수 TS, DOM/DB/three 의존 0, jsdom 단위 테스트 가능
  types.ts                플레이어/적/아이템/이벤트/런 상태/액션 타입
  rng.ts                  시드 PRNG(mulberry32 류) — 결정론, state에 seed 보관·전진
  player.ts               스탯·장비·성장(레벨업) 순수 계산
  enemy.ts                적 테이블 + 깊이 스케일
  combat.ts               턴제 전투 해결(공격/도망/치명, 결정론)
  items.ts                아이템 테이블·사용 효과
  events.ts               이벤트 가중 테이블·해결(선택지 포함)
  dungeon.ts              층/걸음 절차생성(시드 기반)
  run.ts                  reducer: (state, action) => state  ← 모든 규칙 단일 진입
  score.ts                점수 산정

app/play/                 ← 클라 UI(텍스트), 서버 액션(영속은 추후)
  page.tsx                서버: getMemberSession 게이트 → 게임 셸
  game.tsx                "use client" — 런 상태 보유, 로그·HUD·액션 렌더, 키보드
  (이후) actions.ts       리더보드 저장/조회 서버 액션(Prisma)
```

- **순수 리듀서 + 시드 RNG**: `run(state, action)`이 규칙을 강제, RNG는 state의 seed로 전진 → **완전 결정론**(테스트·재현·시드 공유). UI는 state를 그리고 action을 디스패치.
- **영속(추후 슬라이스)**: Prisma `RogueScore`(회원별 최고 깊이/점수) + 서버 액션. 기존 DAL·세션·서버액션 패턴 재사용.
- **번들·서버**: three 제거로 게임 의존 0(일반 React). 512MB 서버·번들 부담 없음.

### 데이터 모델 (영속 슬라이스)

```prisma
model RogueScore {
  id        String   @id @default(uuid())
  userId    String
  seed      String
  depth     Int
  score     Int
  kills     Int
  createdAt DateTime @default(now())
  user      User     @relation(fields: [userId], references: [id])
  @@index([score])      // 리더보드
  @@index([userId])
}
```

## 12. 구현 로드맵 (슬라이스 = PR)

각 슬라이스는 **자체 `docs/plans/...-design.md`(필요시) + PR + 버전 bump + 테스트 + 게이트**.

| 슬라이스      | 내용                                                                                                | 테스트                 |
| ------------- | --------------------------------------------------------------------------------------------------- | ---------------------- |
| **S0** (이번) | 본 기획서 + SRPG 아카이브(코드/의존 제거)                                                           | —                      |
| **S1** ✅     | `lib/game/rogue/` 순수 엔진(rng·player·enemy·combat·items·events·dungeon·run·score)                 | **34건**(결정론 포함)  |
| **S2** ✅     | `/play` 라우트 + 회원 게이트 + **텍스트 UI**(로그·HUD·액션·키보드·aria-live) — 한 런 플레이(무저장) | **6건**(뷰모델 순수부) |
| **S3**        | 콘텐츠/밸런스 확장(이벤트·적·아이템·보스·상점·휴식 다양화)                                          | 신규 로직              |
| **S4**        | **영속·리더보드**(Prisma `RogueScore` + 서버 액션 + `/play` 리더보드)                               | 통합(임시 SQLite)      |
| **S5+**       | 시작 직업/클래스·스킬·시너지·시드 공유 URL·일일 챌린지(고정 시드)·도전과제                          | 신규 로직              |

> 첫 코드 PR은 **S1(순수 엔진 + 테스트)** — 렌더 없이 게임 규칙 전체를 검증해 이후 UI가 얇아진다(SRPG에서 검증된 방식 그대로).

## 13. 비범위(MVP) · 리스크

### MVP 비범위

멀티플레이, 실시간, 그래픽/맵 비주얼, 음성, 방대한 서사, 인벤토리 무한 확장.

### 리스크 · 완화

| 리스크              | 완화                                                            |
| ------------------- | --------------------------------------------------------------- |
| 밸런스(난이도 곡선) | 수식·테이블을 데이터·살아있는 표로, 시드 재현으로 플레이테스트  |
| 콘텐츠 빈약(반복감) | 절차생성 + 이벤트/적/아이템 테이블 확장(S3) + 선택지 분기       |
| 텍스트 단조로움     | 명확한 로그·HUD·짧은 플레이버, 치명/위기 강조                   |
| 범위 폭주           | 슬라이스별 PR, S1=테스트 가능한 순수 엔진부터, 영속은 S4로 분리 |
